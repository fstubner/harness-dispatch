01 — How it works

The problem is route choice, not agent hype.

Codex excels at test-driven execution. Claude does its best work in planning and architecture. Cursor brings editor-aware context. harness-router picks the agent for the task, then delegates through that agent's own CLI — no proxying of the underlying model calls.

Task type

Execute, plan, review — each has a different best-fit agent.

Billing policy

Metered or unknown-billing routes are blocked until you opt in.

Live quota

Routes with available quota are preferred; rate-limited ones are skipped.

Safety profile

read_only, workspace_edit, full_auto gate what an agent can touch.

02 — Setup

Configure is the entrypoint.

One flow detects installed harnesses, verifies auth and route readiness, classifies billing, and writes config.

  1. Detect Claude Code, Codex, Cursor, Antigravity, and configured endpoints.
  2. Verify availability and auth without spending quota where possible.
  3. Choose billing policy, safety profile, and workspace policy per route.
  4. Write config, print an MCP snippet, connect your agent.

04 — Positioning

What it is, and isn't.

CategoryWhat it doesWhat it does not claim
Agent CLIs Delegates to the agents you own, through their official interfaces. It is not a replacement coding agent.
Routing Scores by task type, live quota, billing, safety, and configured priority. It does not measure or advertise token savings.
Protocols Exposes MCP for agents and OpenAI-compatible REST for tools. A2A orchestration is out of scope.
05 — FAQ

Short answers.

Why local only?

Nothing phones home. Traces (if enabled) go to localhost unless you point them elsewhere. The one outbound call is a public leaderboard GET for route scoring.

Why require opt-in for paid routes?

Any route that can incur cost — metered API, unknown billing, subscription overage — is blocked until you set allow_paid_usage: true on it, deliberately.

How is this different from a model proxy?

Proxies swap which model answers your agent's next request. harness-router swaps which agent runs the task — each harness keeps its own scaffolding, tools, and context.

Is it production-ready?

259 tests, smoke tests, cross-platform CI on Windows/macOS/Linux. Small, stable API surface.
